Aplikasi web sederhana untuk mengelola data buku menggunakan **PHP + MySQL** dengan tampilan modern, rapi, dan mudah digunakan.

---

## ✨ Fitur

- Tambah data buku
- Lihat daftar buku
- Edit data buku
- Hapus data buku
- Validasi dasar form

---

## 🚀 Demo Cepat

1. Buka `http://localhost/praktikum_mysql`
2. Klik **Daftar Buku Baru**
3. Isi data buku
4. Simpan
5. Lihat hasilnya di **Katalog Buku**
